# Hướng dẫn sử dụng hình ảnh

## Nguồn hình ảnh miễn phí và hợp pháp

### 1. Unsplash (https://unsplash.com)
- Hình ảnh chất lượng cao, miễn phí bản quyền
- Có thể sử dụng cho mục đích thương mại
- Không cần ghi nguồn (nhưng nên ghi)

### 2. Pexels (https://pexels.com)
- Hình ảnh và video miễn phí
- Giấy phép Pexels cho phép sử dụng tự do
- Không cần ghi nguồn

### 3. Pixabay (https://pixabay.com)
- Hơn 2.7 triệu hình ảnh và video miễn phí
- Giấy phép Pixabay
- Không cần đăng ký

## Cách sử dụng URL từ Unsplash

Format URL Unsplash:
```
https://images.unsplash.com/photo-[ID]?w=[width]&h=[height]&fit=crop
```

Ví dụ:
```
https://images.unsplash.com/photo-1517694712202-14dd9538aa97?w=800&h=600&fit=crop
```

## Thư mục trong dự án

- `/images/products/` - Hình ảnh sản phẩm
- `/images/categories/` - Hình ảnh danh mục
- `/images/banners/` - Banner quảng cáo
- `/images/users/` - Avatar người dùng (nếu cần)

## Lưu ý bản quyền

1. Luôn kiểm tra giấy phép trước khi sử dụng
2. Ưu tiên sử dụng từ Unsplash, Pexels, Pixabay
3. Không sử dụng hình ảnh từ Google Images trực tiếp
4. Nếu có thể, ghi nguồn trong footer hoặc credits page
